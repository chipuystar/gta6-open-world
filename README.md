SOLMARINA is an original open-world crime game in the browser: a sun-soaked coastal city you explore on foot and by car, with traffic and pedestrians, cars to steal and drive, a wanted level with police who chase, ram and bust you, five story missions for Tía Rosa, on-foot shootouts, a HUD with a live minimap, synthesized engine, siren and music audio, and saves in localStorage. Built with three.js (vendored) and vanilla JavaScript — no build step, no network.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
